## 🏢 About

**London Cleaning & Maintenance (LCM)** is the trading name of **Al Yafei International LLC**, one of Oman's top-three Facilities Management companies, established in **1992**. This repository contains the official company website — a modern, fully responsive, single-page application built with plain HTML, CSS, and JavaScript.

---

## 🚀 Features

- **Responsive Design** — Mobile-first layout adapting to all screen sizes
- **Services Showcase** — Tabbed interface for Soft Services (Cleaning & Pest) and Hard Services (MEP & Maintenance)
- **Client Portfolio** — Filterable grid of prestigious government, corporate, and hospitality clients
- **Testimonials Slider** — Auto-playing carousel with official client endorsements
- **Quote Request Form** — Interactive form with client-side validation
- **Premium UI** — Glassmorphism effects, micro-animations, sticky navigation, and smooth scroll
